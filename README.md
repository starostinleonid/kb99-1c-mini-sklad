# kb99-1c-mini-sklad

Учебная конфигурация **«Мини-Склад»** на платформе 1С:Предприятие 8.3 (режим совместимости 8.3.27, управляемое приложение, интерфейс «Такси», язык — русский).

## Что внутри

**Подсистема:** «Мини-склад» — объединяет все объекты ниже; команды создания выведены в интерфейс.

### Справочники

- **Товары** — код строковый (длина 9), наименование 100; реквизиты: `Цена` (10.2, неотрицательное), `Вес` (10.3, неотрицательное).
- **Контрагенты** — код строковый (длина 12), наименование 100; реквизиты: `ИНН` (строка 12), `Адрес` (строка 200).

### Документы

- **Поступление** — реквизит `Контрагент` (СправочникСсылка.Контрагенты); ТЧ `Товары`: `Товар`, `Количество` (15.0), `Сумма` (15.2). При проведении пишет приход по регистру `ОстаткиТоваров` (модуль объекта).
- **Реализация** — реквизит `Покупатель` (СправочникСсылка.Контрагенты); ТЧ `Товары`: `Товар`, `Количество` (15.0), `Сумма` (15.2). При проведении пишет расход по регистру `ОстаткиТоваров` (модуль объекта).

### Регистры накопления

- **ОстаткиТоваров** — вид «Остатки»; измерение `Товар` (СправочникСсылка.Товары), ресурс `Количество` (15.3, допустимый знак — любой). Используется документами «Поступление» и «Реализация» для учёта движений.

## Как открыть

1. Создайте новую **пустую** информационную базу (без конфигурации).
2. Откройте её в **Конфигураторе**.
3. Выберите **«Конфигурация → Загрузить конфигурацию из файлов…»** и укажите папку `src`.
4. Обновите конфигурацию базы данных (**F7**).
5. Запустите **«1С:Предприятие»** (**F5**) — раздел «Мини-склад» появится в интерфейсе.

## Как проверить работу

1. Создайте товар (справочник «Товары») и контрагента (справочник «Контрагенты»).
2. Создайте документ «Поступление»: выберите контрагента, добавьте строку ТЧ с товаром и количеством, проведите документ.
3. Откройте регистр «ОстаткиТоваров» — по товару должен появиться приход.
4. Создайте документ «Реализация» на тот же товар и проведите — остаток уменьшится.

## Структура репозитория

```
src/
├── Configuration.xml           — корневые свойства конфигурации
├── ConfigDumpInfo.xml          — служебный файл выгрузки
├── AccumulationRegisters/
│   └── ОстаткиТоваров.xml      — регистр накопления «Остатки товаров»
├── Catalogs/
│   ├── Товары.xml
│   └── Контрагенты.xml
├── Documents/
│   ├── Поступление.xml
│   ├── Поступление/Ext/ObjectModule.bsl    — проведение (приход)
│   ├── Реализация.xml
│   └── Реализация/Ext/ObjectModule.bsl     — проведение (расход)
├── Languages/
│   └── Русский.xml
└── Subsystems/
    ├── Минисклад.xml
    └── Минисклад/Ext/CommandInterface.xml
```

## Примечания

- `src` — выгрузка конфигурации в файлы (XML) для версионирования в Git. `config/1Cv8.cf` — бинарный файл конфигурации для быстрого развёртывания.
- Служебные файлы 1С (`.cfl`, `.log`, `.dt` и т.п.) в репозиторий не добавляются.
- Для работы с этим репозиторием на машине разработчика используется отдельный SSH-ключ и remote-псевдоним `github-second`.
