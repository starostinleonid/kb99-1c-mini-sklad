# kb99-1c-mini-sklad

Учебная конфигурация **«Мини-Склад»** на платформе 1С:Предприятие 8.3 (режим совместимости 8.3.27, управляемое приложение, интерфейс «Такси», язык — русский).

## Что внутри

**Подсистема:** «Мини-склад» — объединяет все объекты ниже; команды создания выведены в интерфейс.

**Справочники:**
- **Товары** — код числовой (длина 9), наименование 100; реквизиты: `Цена` (10.2, неотрицательное), `Вес` (10.3, неотрицательное).
- **Контрагенты** — код строковый (длина 12), наименование 100; реквизиты: `ИНН` (строка 12), `Адрес` (строка 200).

**Документы** (проведение разрешено, движения по регистрам не настроены):
- **Поступление** — реквизит `Контрагент` (СправочникСсылка.Контрагенты); ТЧ `Товары`: `Товар`, `Количество` (15.0), `Сумма` (15.2).
- **Реализация** — реквизит `Покупатель` (СправочникСсылка.Контрагенты); ТЧ `Товары`: `Товар`, `Количество` (15.0), `Сумма` (15.2).

## Как открыть

1. Создайте новую пустую информационную базу в 1С:Предприятие 8.3 (файловый вариант достаточно).
2. Откройте её в Конфигураторе.
3. Выберите **«Конфигурация → Загрузить конфигурацию из файлов…»** и укажите папку `src`.
4. Обновите конфигурацию базы данных (**F7**).
5. Запустите **«1С:Предприятие»** (**F5**) — раздел «Мини-склад» появится в интерфейсе.

## Структура репозитория

```
src/
├── Configuration.xml        — корневые свойства конфигурации
├── Catalogs/                — справочники (Товары, Контрагенты)
├── Documents/               — документы (Поступление, Реализация)
├── Languages/               — язык интерфейса (Русский)
└── Subsystems/              — подсистема «Мини-склад» и её CommandInterface
```
